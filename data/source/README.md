# Boundary source snapshot

`jinbocho-towns.geojson` is a three-feature extract for 神田神保町一〜三丁目 from the census small-area boundary data used by CHiYODA ATLAS.

- Source: 国勢調査町丁・字等別境界データセット
- Creator: CODH / ROIS-DS Center for Open Data in the Humanities
- Source page: <https://geoshape.ex.nii.ac.jp/ka/>
- License: CC BY 4.0
- Extracted: 2026-09-22
- Processing: selected the three matching town features and retained geometry plus a minimal source field

The boundary is a statistical boundary and may not match a legally surveyed address boundary in every detail.
