# データ作成・表示方法

## 対象範囲

初版は、街の中心を高密度に調べるため、神田神保町一丁目・二丁目・三丁目を対象とします。千代田区都市計画マスタープラン上の「神保町地域」全体（西神田、三崎町、猿楽町、一ツ橋、駿河台を含む）とは異なります。

## 4つの実体を分ける

1. `buildings`: 物理的な建物ポリゴン
2. `places`: 店舗・施設。建物ID、階、業種、履歴を持つ
3. `frontages`: 1階の実際の間口線。現地調査後に追加予定
4. `alleys`: 路地・細街路・抜け道。通行可否や段差等は現地調査後に追加予定

一棟に複数の店が入るため、建物色は店舗の階情報がある場合は地上階（OSMの `level=0`、日本式表記の1階）を優先します。地上階の店が確認できず、階情報がない店だけがある場合は、その店を路面店候補として色付けします。2階・地下など非地上階の店しか確認できない建物は未分類です。建物全体の用途や床面積割合ではありません。

## 建物

初版の建物形状は東京都「令和3年度区部土地利用現況調査」の建物現況ポリゴンを神田神保町一〜三丁目で切り出し、WGS84へ変換して簡略化したものです。属性は地図表示に必要なID、階数等に限定します。原Shapefileは容量・配布条件・再現性の観点からリポジトリへ含めません。

## 白地図

町丁目の地面、道路、歩道、建物を個別に描きます。道路面はOpenStreetMapの道路中心線から作り、幅タグがない場所は道路種別に応じた作図上の幅を使います。歩道面は `footway=sidewalk` として登録された線だけから作ります。道路と歩道の外縁は測量済みの境界や土地の所有境界を示しません。

通り名はOpenStreetMapで名称が確認でき、対象範囲内で表示に足る長さのある道路の代表線に置きます。丁目名はCODHの町丁目境界をもとに表示します。対象範囲の外側にはOpenStreetMapの既存地図を淡く敷き、白地図の下に隠します。白地図の生成元は `data/raw/osm-basemap.xml.gz`、生成コードは `scripts/build_basemap.py` です。

## 店舗

OpenStreetMapの `shop` と飲食・文化系 `amenity` を候補として取得し、町丁目内へ切り出します。古書店の創業年など、重要な値は店舗公式サイト・公式観光情報等を一件ずつ確認し、`data/curated/places.json` で上書きします。

OSMだけの店舗は「OSM参考」、公式ページ等で照合した店舗は「公式情報確認」と表示します。営業状況・営業時間は変わるため、確認日を必須とします。

紹介文は `description` に短くまとめ、専門分野・名物など出典で確かめられる特徴を記録します。歴史情報と紹介文の出典が異なる場合は `descriptionSourceUrl` と `descriptionSourceLabel` を併記します。紹介文も検索対象です。

拡大時の店名は建物ポリゴン上に1棟1ラベルを置き、文字が重なるものを自動で間引きます。複数店舗が入る建物は代表の店名と他店数を表示し、押すと店舗一覧で確認できます。

## 年代

以下を混同しません。

- `foundedYear`: 店・事業の創業年
- `jinbochoOpenedYear`: 神保町での開業年
- `currentLocationSince`: 現在地への移転年
- 将来追加する `buildingCompletedYear`: 現建物の竣工年

地図の「古書店年代」は `foundedYear` を使います。由来が別地域の創業である場合は詳細カードに明記します。

## 「人気」の扱い

Google Mapsや食べログの点数・口コミは取得・保存・転載しません。「人気店」という主観的な単一スコアも作りません。代わりに、神田カレーグランプリ受賞、公式観光サイト掲載、歴史的建物指定など、名称・年・出典が追える掲載根拠を表示します。

## 今後の現地調査

高精度版では、すずらん通り周辺から次を現地確認します。

- 店舗入口と階
- 1階間口の線
- 空き店舗・営業時間帯
- 路地幅の区分、段差、通り抜け、アーケード
- 店先の書棚・ワゴン・ベンチ
- 建物と店の写真（撮影・公開許諾を確認）
